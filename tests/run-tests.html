Field Inspect — Automated Test Suite

Zero-dependency, browser-native tests — no Node/npm required. Runs against an isolated field-inspect-db-test IndexedDB (via ?test=1), so it never touches real job data. The DB suite exercises db.js directly; the UI suite drives the real app in the iframe below, bypassing login the same way manual QA does (never enters credentials — calls the app's own showJobListView() hook, which is a no-op against the live backend since no session exists).
